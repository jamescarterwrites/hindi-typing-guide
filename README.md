# Hindi Typing Guide
Type Hindi using English letters (Hinglish), for example "namaste" becomes "नमस्ते".
Write words the way they sound, keeping common spellings consistent.
Use "aa" for long "a" sounds, such as "aap", and "ee" for long "i" sounds, such as "jeevan".
Add "h" after letters for aspirated sounds, for example "kh", "gh", "ch", "jh", "th" and "ph".
Check the Devanagari output before copying it, especially for doubled letters and nasal sounds.
Practise short everyday sentences first, then move to longer messages and paragraphs.
